# Projectile Motion in Python

*A computational and pedagogical framework for projectile motion using Python.*

---

## Repository under development

This repository is being developed as a companion resource for the article

**"A computational and pedagogical framework for projectile motion using Python visualizations."**

The project presents analytical and numerical implementations of three projectile-motion models with increasing physical and mathematical complexity:

- Ideal projectile motion
- Projectile motion with linear air resistance
- Projectile motion with quadratic air resistance

The repository is currently under active development.

The comparison figure of the three models and the corresponding Python implementations will be added progressively.
